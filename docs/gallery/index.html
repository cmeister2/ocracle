Data and notes

These are fixed crops and recorded neural OCR results. References follow the pictured printing. Confidence is an uncalibrated model score; it can be high when the text is wrong. Case, punctuation and accents count toward character error rate (CER).

Blur uses Gaussian σ = 2.4 source pixels followed by downsampling to 30%. The smaller files are displayed at the original crop width for comparison. OCR uses the default model and its original-image pass.

These few examples do not establish complete font or language coverage. Pretrained model training membership is unknown. Reproduction and methodology
